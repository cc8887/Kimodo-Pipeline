# Idle 参考、固定大臂与小臂摆动

`run --scope locomotion` 使用 `upright_feminine_rules.json`，覆盖无道具 Walk、Run、Sprint、关联姿态表、Lean、加速、起停、脚部过渡、转身和蹲站。Idle 与基础站姿作为身份参考；Jump、Land、Roll、Air、Mantle 和道具不在此制作范围。

当前策略 `locomotion-idle-forearm-v2` 按 2026-10-12 的风格要求区分站立与蹲伏：站立移动的背部接近 Idle，脖子和头更直；大臂相对胸部固定贴身，小臂带动双手明显前后移动。蹲伏保留原脊柱和胸部前倾，不套用站立的直立背部。提示词描述这些可观察的动作；女性化风格仍须检查实际显示模型。

Idle 同时用于运行中的 SecondaryMotion 叠加；只修改移动循环仍会由该叠加带回大臂摆动。因此 `idle_arm_posture` 单独固定 Idle 的 Shoulder／Arm 相对胸部旋转，逐字保留原呼吸脊柱、颈／头、小臂、手腕和下肢。其参考中间帧保持原姿态，移动上身仍使用实际交付的 Idle 作为基准。

## 制作与时间

实际 Idle 的中间帧提供胸部相对的肩／大臂方向。站立脊柱的全局旋转保留 15% 的源动作偏差，颈／头保留 8%；SO(3) 插值后反解局部旋转，补偿骨盆倾斜。蹲伏的 Spine1／Spine2／Chest 局部旋转逐字保持源动作。姿态表分别识别站立和蹲伏帧；蹲站保留蹲姿部分。

肩与大臂的全局方向由当前胸部旋转和 Idle 胸部相对旋转共同确定，因此可随身体转向、蹲伏和倾斜，但自身没有摆臂。循环的小臂围绕休息弯曲角摆动 22°，双手分别沿胸部前后／上下移动；相位取实际足部轨迹的一阶谐波，与同侧腿相反。周期首尾采用零角速度／加速度的时间变化，维持现有整骨架接缝门禁。瞬态动作保留 85% 的源小臂变化；手腕和指节保持源局部动作。

Root、骨盆、所有腿部局部旋转和脚部 FK 保持。每次源编辑保存 `posture-authoring.json`、源／结果姿态摘要、被保留的蹲姿帧；原始 Kimodo 结果保留，编辑后的动作明确记为离线制作。

新生成循环在裁出最终周期后再次烘焙小臂，并复验全部原步态条件。其他关联姿态在最终冻结、镜像、组合、偏转后重新制作上身，再执行风格门禁，以免姿态表带回不同的大臂方向。Lean 的配方偏转为 3°、加速为 2°，这些数据不代表最终游戏每帧的倾斜角。

## 验收与来源

站立背部、全部颈／头的前倾／下俯相对实际 Idle 允许新增 8°，逐项检查中位值与最大值。大臂外展在完整胸部坐标系测量，相对 Idle 允许新增 12°，不会把蹲伏的躯干侧倾算成大臂展开。大臂相对胸部的旋转变化上限 0.05°；移动循环的每侧手部位移范围至少 8 cm。蹲姿背部保持在制作阶段以原始局部旋转直接校验，门禁不要求蹲姿直立。

这些新增风格检查不更改原步态、原生对照、接触、接缝和修复预算。失败保留 `rejected-locomotion-posture.npz` 和独立报告并阻断该交付。风格报告绑定真实源姿态数组、源 NPZ、交付 NPZ 和自身文件 SHA256；转换与发布拒绝缺失、失败、被修改或属于另一动作的证据，报告随包的 `locomotion-posture/` 清单登记。

`restyle_gait` 可显式复用已有合格 Kimodo 下肢循环：先核验执行回执、rig、源 NPZ 和原门禁摘要，按当前阈值复验原循环，修改上身，再对新结果复验全部周期和风格条件。此路径不计为新 diffusion。原失败候选保留；旧资产回退不能算本轮新风格成功。V1 整体缩小上身摆动的旧策略仅为历史回执兼容保留，不作为当前配方。

范围外保留的交付绑定其原执行的 `sourceAuthoringReceipts` 文件和摘要。重新制作 Run 时，同名节点不能替换已保留 Jump 的历史 Run 支撑来源；Jump 仍针对真实原依赖重放其原 10 cm 支撑门禁，最终游戏交接另行实测。

新包执行纯脚本重定向、Root／Pelvis 分解、逐资产曲线、最终 FBX 回读、Godot 导入和相关实际场景。包不完整或游戏质量失败时仍保留诊断交付与失败清单，不自动修改消费者默认指针。实际批次证据见验证目录。
